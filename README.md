# 周澤豐＆簡亞婕 婚禮報到系統（2026.09.27）

手機版一頁式工具，供婚禮當天：
1. 搜尋賓客姓名／綽號／桌號 → 顯示桌次＋座位平面圖，快速帶位
2. 登記報到、喜餅（送客小禮）
3. 登記月餅（僅女方 13 組家庭名單，一家一盒；非名單內賓客可在「彈性登記」區塊手動處理）
4. 即時流程時間軸（文定／迎娶／證婚午宴），顯示目前進行到哪個階段、倒數下一階段、該階段重點提醒

## 架構
- 前端：這個資料夾（純靜態 HTML/CSS/JS），部署在 GitHub Pages
- 後端／資料庫：Google Apps Script Web App + 綁定的 Google 試算表（`Guests`、`Families` 兩個分頁），程式碼在本機 `../apps-script/`（未進 git，直接用 `clasp push`/`clasp deploy` 管理）
- `config.js` 存放 API 網址與存取金鑰（金鑰只用來防止路人亂改資料，非高安全性用途）

## 資料來源
賓客與桌次資料整理自 `結婚.xlsx`（A3宴會入座圖＝正式姓名與桌卡；婚禮名單＝綽號與男女方分類），月餅家庭名單依使用者提供的 13 組「一行一家」清單比對而來。

## 重要：Apps Script 一次性授權
Google Apps Script 網頁應用第一次啟用匿名存取前，開發者本人需要在瀏覽器手動點過一次授權（Google 的標準流程，非本系統 bug）。若之後 API 又回傳「存取遭拒」，代表授權過期，需要本人重新點一次部署網址並完成「進階 → 前往（不安全）→ 允許」。
